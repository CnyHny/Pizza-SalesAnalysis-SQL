# Pizza Sales Analysis Using SQL

## Project Overview
This project analyzes pizza sales data using SQL to understand sales performance, popular pizza types, and revenue trends.

## Dataset
This project uses four CSV files:
- orders.csv
- order_details.csv
- pizzas.csv
- pizza_types.csv

## SQL Questions Solved
I solved 13 SQL questions covering three levels of analysis.

### Basic Analysis
1. Total number of orders
2. Total revenue
3. Highest-priced pizza
4. Most common pizza size
5. Top 5 most ordered pizza types

### Intermediate Analysis
6. Quantity ordered by pizza category
7. Order distribution by hour
8. Category-wise distribution of pizzas
9. Average pizzas ordered per day
10. Top 3 pizza types by revenue

### Advanced Analysis
11. Percentage contribution of each pizza type to total revenue
12. Cumulative revenue over time
13. Top 3 pizza types by revenue in each category

## Tools Used
- SQL
- CSV datasets
- GitHub

## Project Objective
To practice SQL queries and analyze pizza sales data to generate meaningful business insights.
