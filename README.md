 # Pizza Sales Analysis Using SQL

## Project Overview
This project analyzes pizza sales data using SQL to understand sales performance, popular pizza types, order patterns, and revenue trends.

## Dataset
The project uses four CSV files:
- `orders.csv`
- `order_details.csv`
- `pizzas.csv`
- `pizza_types.csv`

## SQL Analysis
A total of 13 SQL questions were solved across three difficulty levels.

### Basic Analysis
1. Total number of orders
2. Total revenue
3. Highest-priced pizza
4. Most common pizza size
5. Top 5 most ordered pizza types by quantity

### Intermediate Analysis
6. Total quantity by pizza category
7. Order distribution by hour
8. Category-wise pizza distribution
9. Average pizzas ordered per day
10. Top 3 pizza types by revenue

### Advanced Analysis
11. Percentage contribution of each pizza type to total revenue
12. Cumulative revenue over time
13. Top 3 pizza types by revenue within each category
